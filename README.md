A one-line comeback for make.fun's "The Moon Finally Answers Back" bounty. The entry is a tiny Node program that validates a single original line — one line, under 240 characters, in the Moon's own voice — and writes it to `entry.txt`, nothing else. The Moon has listened to four billion years of wishes, howls, and 2 a.m. promises without ever being asked how it's doing, and it answers the way only a tired old rock can: it glows, it's fine, and your ex isn't coming back.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
